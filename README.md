# Skill Tree Mod

A Minecraft mod that adds a skill tree system similar to Passive Skill Trees. It includes a building tool to customize the skill tree, skill points displayed above the hotbar based on skill level, and skill points earned through skill bottles, mob kills, or custom NPC kills. A full hotbar indicates an available skill point for the skill tree, with skill level increasing with each full hotbar achieved.

## Install

1. Download the mod jar file.
2. Place the jar file in the `mods` folder of your Minecraft installation.
3. Launch Minecraft with Forge 1.12.2 installed.

## Use

1. **Building Tool**: Use the building tool to customize the skill tree.
2. **Skill Points**: Earn skill points through skill bottles, mob kills, or custom NPC kills.
3. **Skill Tree**: Open the skill tree GUI to view and upgrade your skills.
